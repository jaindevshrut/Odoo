# ReWear - Community Clothing Exchange Platform

**Team Name:** Crawlers

## 🎯 Problem Statement
ReWear is a community-driven platform for exchanging clothing items, promoting sustainability and reducing fashion waste through peer-to-peer clothing exchange.

## 📁 Repository Structure

This repository contains two main projects:

### 1. **Frontend** (`/rewear-new`)
- React-based user interface
- Features: Item browsing, user dashboard, admin panel, authentication

### 2. **Backend** (`/Backend`)
- Node.js/Express RESTful API
- MongoDB database
- JWT authentication
- File upload with Cloudinary integration

## 🚀 Quick Start

### Prerequisites
- Node.js (v14 or higher)
- MongoDB (local installation or MongoDB Atlas account)
- Cloudinary account (for file uploads)

### Backend Setup
```bash
cd Backend
npm install
cp .env.example .env
# Edit .env with your configuration
npm run dev
```

See [Backend/README.md](Backend/README.md) for detailed instructions.

### Frontend Setup
```bash
cd rewear-new
npm install
npm start
```

See [rewear-new/README.md](rewear-new/README.md) for detailed instructions.

## 🛠️ Technology Stack

### Frontend
- React.js
- React Router
- CSS3

### Backend
- Node.js
- Express.js
- MongoDB with Mongoose
- JWT for authentication
- Bcrypt for password hashing
- Multer for file uploads
- Cloudinary for cloud storage
- CORS for cross-origin requests
